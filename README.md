# Eduarte Calixto — Mega Tech Portfolio

Portfólio estático responsivo em HTML, CSS e JavaScript, preparado para GitHub Pages.

## Como executar
Abra `index.html` no navegador ou publique os arquivos na raiz do repositório GitHub Pages.

## Estrutura
- `index.html` — conteúdo e metadados SEO/social.
- `css/style.css` — identidade visual, layouts responsivos, animações e acessibilidade.
- `js/main.js` — menu mobile, reveal ao rolar, ano automático e botão voltar ao topo.

## Antes de publicar
- Confira se o e-mail e os perfis sociais continuam corretos.
- Adicione links reais para os repositórios dos projetos quando estiverem públicos.
- Inclua apenas tecnologias e competências que consiga discutir em uma entrevista.
- Considere adicionar um currículo PDF e capturas reais dos projetos.
